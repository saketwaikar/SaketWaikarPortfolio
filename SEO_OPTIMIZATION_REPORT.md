### 5. **Technical SEO Files**

#### **robots.txt**
- Allows all crawlers to index the site
- References sitemap.xml for discovery
- Configures crawl-delay for different bots
- Protects temp/private directories

```txt
User-agent: *
Allow: /
Sitemap: https://saket.waikar.me/sitemap.xml
```

#### **sitemap.xml**
- Lists all important pages with priority
- Home page: priority 1.0 (highest)
- About/Resume: priority 0.8-0.9
- Helps Google discover and crawl all pages

```xml
<url>
  <loc>https://saket.waikar.me/</loc>
  <priority>1.0</priority>
  <changefreq>weekly</changefreq>
</url>
```

#### **.htaccess**
- **Gzip Compression** — reduces page load time by ~70% (improves Core Web Vitals)
- **Browser Caching** — improves repeat visitor performance
- **www Removal** — canonicalizes to non-www version (SEO best practice)
- **Security Headers** — X-UA-Compatible, X-Content-Type-Options, X-Frame-Options
